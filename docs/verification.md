The Docker failure test deliberately substitutes a failing builder for an uncached environment and checks preservation of the prior container/image/files. The memory test exhausts a limited project's memory and verifies that it can recover its files. Restore tests recover password hashes, metadata, encryption keys/variables, project files, and home configuration. The operator smoke additionally validates complete Compose downtime and restoration.

Linux AMD64 and ARM64 CI jobs are defined in `.github/workflows/ci.yaml`; they have **not been run from this workspace**. Intel macOS, native Linux installations, external HTTPS proxies, and browser engines other than Chromium have not been verified locally. Runtime image tags provide manifests for both target architectures, but manifests are not a substitute for native installation tests.

The Monaco bundle is lazy-loaded for the workspace and is approximately 1 MiB compressed. Vite reports a large-chunk warning; the dashboard/setup do not eagerly load the editor. Further bundle optimization is possible.

The Compose smoke runner requires an explicitly disposable Compose project and environment file; it refuses a project name outside `repellet-smoke*`. It can be run with `COMPOSE_PROJECT_NAME=repellet-smoke REPELLET_ENV_FILE=/path/to/smoke.env node tests/compose-smoke.mjs` after creating the matching installation. Do not point it at personal project data.

## Runnable projects, workspace usability, and GitHub App validation

The milestone changes were validated on macOS ARM64 with Docker Desktop. `npm run check` passes 36 unit/database tests; `npm run test:e2e` passes four browser scenarios. Browser coverage includes both starter creation/preparation/Run/edit/preview loops, process replacement, refresh with no dependency reinstall, keyboard file opening, multiple-tab diagnostics, diagnostic navigation, rename/delete updates, restored panels/tabs, collaborator preference isolation, and a cross-site GitHub redirect completed with the existing SameSite=Strict cookie.

A local fake GitHub service covers authorization-state replay/expiry/account binding, owner-only configuration and secret redaction, app/user access intersection, read-only versus write users, concurrent expired-token refresh, revoked access, disconnect, and reconnect. Real Docker tests additionally cover separate staged/unstaged diffs, branch discovery, operation-token error redaction, absence of persisted helper/token configuration, and refusal after an origin change. Backup restoration checks the new encrypted app configuration/member tokens and starter/preparation metadata.

Preparation tests cover exclusive/resumable scaffolding, bounded logs, step timestamps/outcomes, unchanged dependency reuse, failed installation retries with a healthy editor, cancellation, interrupted-job reconciliation without automatic installation, responding HTTP errors, and the 60-second readiness guidance without stopping the app or extending idle activity. The workspace base image is now `repellet/workspace-base:0.2.0`, ensuring upgrades rebuild the bridge rather than retaining old endpoints.

Representative local cached-runtime measurements: React scaffolding/install preparation **2.60 seconds**, Python preparation **4.62 seconds**; separate workspace starts **1.16** and **1.51 seconds**. A Node runtime build with uncached runtime layers and an already cached base image took **3.64 seconds**. These are local observations, not latency guarantees or a complete cold installation benchmark. Fresh base-image/registry downloads and Go/Rust tool compilation can take minutes. Browser tests write token-free timing data to `.cache/workflow-timings.json`; the separate build measurement is `.cache/runtime-benchmark.json`.

Live GitHub smoke testing is **pending**, because no actual configured GitHub App, designated disposable private repository, or two authorized test accounts were supplied. Follow the [live smoke procedure](workflows.md#disposable-live-smoke-procedure) and record results before rollout to members. Linux AMD64/ARM64 workflows are defined but were not executed from this workspace. No claim is made for macOS AMD64 or non-Chromium browsers.
